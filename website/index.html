GOOD TO KNOW

A few things,
before you connect.

Is LazyRemote another remote desktop service?

It is a native control room for your own remote-access infrastructure. LazyTunnel handles SSH and forwarding; an existing noVNC service supplies the desktop. It does not install a screen-capture or input driver, and it leaves UU, RDP and VNC sessions alone.

Do I need my own server?

For connections between separate private networks, use a reachable server running the LazyTunnel relay. The optional controller currently runs on Linux/systemd. The apps can reach it through verified SSH, including one cloud jump host.

Can I install it from the app stores?

This is a source and build preview, not an App Store or Play Store launch. Android has signed APKs. Desktop bundles are available with installation instructions. iOS builds require your Apple signing and device provisioning; no public iOS install is promised.

Can several people use one server with separate accounts?

Yes. LazyTunnel CLI 0.3.0 lets you run a personal relay or invite multiple independent accounts. Each account has its own devices and SSH permissions. Users enroll with a key or password through a pinned invitation; the native apps still use the local controller. See the account setup guide. Public signup and billing are not included.

Can I install the server and client with npm?

Yes. Run npm install -g @lazyingart/lazytunnel for the cross-platform client and Linux relay commands. Then follow the npm setup guide to enroll your devices. Installing the package does not start services or change your existing remote desktops.

What keeps running if I close the app?

Your endpoint carriers, controller agent, and persistent managed forwards continue independently. The native app’s interactive SSH sessions and viewer connections end on disconnect. On phones, keep the app in the foreground while using those connections.

Does this website connect to my devices?

No. This is a static launch site with no login, no tracking scripts, and no connection to your private agent. Open the installed app or your private web console to connect.
