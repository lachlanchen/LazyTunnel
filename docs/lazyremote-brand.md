# LazyRemote identity and launch assets

LazyRemote is the public product identity at https://remote.lazying.art.
LazyTunnel remains the independent transport/controller project and the name of
the current native preview. This naming does not migrate credentials, rename
installed application identifiers, or change any SSH command.

The identity uses a cobalt-blue folded portal, warm ivory backgrounds, deep
ink text and restrained sage panels. The portal suggests a route into one's
own workspace. The site uses local system fonts with an italic serif accent;
no third-party font request is required.

## Generated logo

File: `website/assets/lazyremote-logo.png`.
Generated on 2026-09-09 using Codex's built-in image generator, not a paid API
fallback. The original generated PNG was copied into the repository with its
transparency intact. No private data or external brand reference was supplied.

Generation prompt:

> Use case: logo-brand. Create a final, distinctive logo symbol for LazyRemote, a lightweight self-hosted remote access app from LazyingArt that connects one's computers, terminals and private desktops. Asset type: standalone production logo icon for a modern app and website. A single confident geometric symbol, an abstract lowercase flowing r or two open rounded doorways joined by a continuous bent ribbon, suggesting a calm portal and effortless connection. Rich electric cobalt blue, with a tiny cyan accent only if it improves the shape; restrained, flat vector-like graphic, crisp edges, memorable negative space, balanced asymmetry. No stock chain link, no cloud, no globe, no cursor, no laptop illustration. No text or letters written as typography, no slogan, no watermark, no mockup sheet, no surrounding border. One large centered mark, generous clearspace, square 1024x1024 canvas, genuinely transparent background. Readable as a small 32px app icon. Premium independent software studio identity; precise, friendly, beautiful, simple.

## Screenshot provenance

The native desktop light/dark and Android pictures are genuine application
captures, not generated UI mockups. The app received sample inventory from
`scripts/demo-agent.py`; labels and timing values belong to that fixture, not
the operator's real computers. No real access code or endpoint configuration
appears in the images. The site labels this distinction below the hero.

`website/assets/social-card.png` is a 1200×630 browser capture of the site's
actual hero. It is used for link previews. The full website screenshots are
saved as release evidence separately from browser profiles and runtime logs.

The application continues using the existing LazyTunnel icon for this preview;
the LazyRemote logo is the website/product identity. Both roles are explicit,
so operators do not need to rename a working installation.
